# FocusLock V3 | Intelligence

## Vision
Transform FocusLock into a futuristic academic command centre.

## Design
- Midnight navy background
- Electric cyan and violet accents
- Clean cards and readable typography
- Smooth animations
- Large, accessible buttons
- Real statistics only

## Main Modules

1. Command Centre
   - Today's study time
   - Daily goal progress
   - Active study session
   - Streak and quick actions

2. Study Engine
   - Subject management
   - Chapter and topic tracking
   - Study timer
   - Session history

3. Study Planner
   - Weekly timetable
   - Tasks and deadlines
   - Study scheduling

4. Revision Centre
   - Revision queue
   - Configurable revision intervals
   - Revision history

5. Intelligence
   - Daily, weekly, monthly and yearly analytics
   - Subject-wise reports
   - Study consistency calendar
   - Planned versus actual study time

6. Focus Control
   - App-blocking profiles
   - Focus session limits
   - Pause controls
   - Essential device access

7. Data Centre
   - CSV export
   - Backup and restore
   - Data management

## Technical Architecture
- Java 17
- Android XML layouts
- Local-first architecture
- Repository pattern
- Gradual database introduction
- Preserve existing package ID: com.focuslock.app
- Migrate V2 data wherever possible
